# [설계 결정] Java/Spring 버전

- 날짜: 2026-11-16
- 관련 이슈: #1 (버전 확인은 개발 환경 세팅 이슈에서 이어서 한다)

## 상황

새 백오피스 프로젝트의 언어와 프레임워크 버전을 정해야 했다.

## 선택지

- Java 21 + Spring Boot 3.5
- Java 21 + Spring Boot 4.x
- Java 25 + Spring Boot 4.x

## 결정

Java 25 (LTS) + Spring Boot 4.x

## 이유

- 지원 기간이 가장 긴 LTS다.
- 가상 스레드를 외부 연동·타임아웃 문제에 활용할 수 있다.
- AI가 만든 예전 버전 방식의 코드를 검증하는 경험이 [AI 검증] 기록이 된다.

## 감수한 점

- 참고 자료가 적고, 라이브러리 호환 위험이 있다.
- 현업에 많은 Boot 3 환경과 차이가 있다.
- LTS가 아닌 버전(26, 27)은 지원 기간이 6개월이라 제외했다.

## 확인 사항

- [ ] Java 25와 Spring Boot 4.x의 공식 지원 일정 확인
